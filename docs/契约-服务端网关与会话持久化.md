# 契约: Bun.serve 本地服务网关与 SQLite 会话持久化

## 1. 功能契约目标
本契约定义本地 Server Sidecar 的 API、WebSocket 与持久化边界，对标 `D:\claude code` 的 `src/server/index.ts`、`src/server/ws/events.ts` 与 `src/server/services/sessionService.ts`。

---

## 2. HTTP REST 契约

### 2.1 启动探针 `GET /health`
- **输入**: 无参数。
- **输出**: `200 OK`，JSON 响应体：
  ```json
  {
    "status": "ok",
    "runtime": "bun",
    "version": "<bun-version>",
    "timestamp": "<ISO-8601>"
  }
  ```
- **不变量**: 零鉴权、无阻塞、不依赖外部网络。

### 2.2 会话管理 API
- **`GET /api/sessions`**:
  - 返回所有历史会话列表，按 `updatedAt DESC` 排序。
- **`POST /api/sessions`**:
  - 输入: `{ "workDir": string, "title"?: string }`
  - 输出: `201 Created`，返回包含 `id`, `workDir`, `title`, `createdAt`, `updatedAt` 的新会话对象。
  - 副作用: 在 SQLite `sessions` 表中写入新记录。
- **`DELETE /api/sessions/:id`**:
  - 输出: `200 OK`，`{ "success": true }`。
  - 副作用: 从数据库彻底删除会话及级联消息，并断开任何现有长连接。

## 3. WebSocket 通信契约 (`/ws/:sessionId`)

### 3.1 握手与连接生命周期
- **握手地址**: `ws://127.0.0.1:3456/ws/<sessionId>`
- **建立后立即发送的两条消息**:
  1. `{ "type": "connected", "sessionId": "<sessionId>" }`
  2. `{ "type": "session_state", "turnState": "idle" }`
- **心跳机制**:
  - 客户端发送 `{ "type": "ping" }`，服务端必须在 100ms 内响应 `{ "type": "pong" }`。

### 3.2 任务触发与流式推送契约
- **客户端发送 `{ "type": "user_message", "content": string }`**:
  - 服务端广播 `{ "type": "session_state", "turnState": "running" }`
  - 服务端广播 `{ "type": "status", "state": "thinking" }`
  - 模型生成思考: 广播 `{ "type": "thinking", "text": string }`
  - 模型生成文本: 广播 `{ "type": "content_delta", "text": string }`
  - 工具调用发起: 广播 `{ "type": "content_start", "blockType": "tool_use", "toolName": string, "toolUseId": string }`
  - 工具执行完毕: 广播 `{ "type": "tool_result", "toolUseId": string, "content": unknown, "isError": boolean }`
  - 任务闭环: 广播 `{ "type": "message_complete" }` 与 `{ "type": "session_state", "turnState": "idle" }`

### 3.3 人工权限审批契约
- 工具触发审批时，服务端广播:
  ```json
  {
    "type": "permission_request",
    "requestId": "req_...",
    "toolName": "...",
    "toolUseId": "...",
    "input": { ... },
    "description": "..."
  }
  ```
- 客户端响应 `{ "type": "permission_response", "requestId": "req_...", "allowed": boolean }`:
  - 服务端广播 `{ "type": "permission_resolved", "requestId": "...", "allowed": boolean }`
  - 若 `allowed === true`，恢复工具执行；若 `allowed === false`，向 Agent 上下文注入驳回信息。
